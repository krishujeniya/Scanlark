image to text.

A few practical answers

Before you begin.

Scanlark is an open-source Flutter OCR application. Its source includes camera and gallery image selection, Google ML Kit text recognition, an editable results screen, Firebase-backed history, and a QR generator.

No. This is a static project website hosted through GitHub Pages. The illustrations explain the app's features. OCR runs in the Flutter app rather than on this page.

The Flutter code saves recognized text and a timestamp under the signed-in user's record in Cloud Firestore. Review your own Firebase configuration and rules before using the app with personal documents.

Yes. The repository is public. Browse the source, review its MIT license, and open an issue on GitHub with a reproducible description.
