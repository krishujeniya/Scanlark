# Scanlark — Icon-only logo kit

A full border-free, text-free export set based on the approved Scanlark bird, document and scanning-light mark.

## Package contents

- `master/`: original-resolution transparent cutout.
- `transparent/`: transparent RGBA PNGs from 16 to 2048 pixels.
- `background-dark/` and `background-light/`: borderless app backgrounds.
- `monochrome/`: simple white, navy and mint icon silhouettes.
- `android/`: standard launcher-size PNGs, Play Store asset, adaptive foreground/background layers.
- `ios/AppIcon.appiconset/`: opaque iOS app icons plus `Contents.json`.
- `web/`: favicon ICO and PNGs, Apple touch icon and PWA icons.
- `social/`: profile picture and textless sharing banners.

## Notes

- The original rounded-square outer frame and all lettering have been removed. The scanner brackets inside the mark are part of the logo and remain.
- Transparent files have alpha; iOS/app-store and platform icons use opaque borderless dark backgrounds where necessary.
- Assets are raster PNGs, not a true editable vector. The 2048 px export is resized from a smaller original.
- Verify the full identity and any rights or brand conflicts before publishing commercially.
